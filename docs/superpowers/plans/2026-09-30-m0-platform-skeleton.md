# M0 Platform Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the Sentech Connect platform skeleton — a hardened docker-compose stack (Postgres/PostGIS, Redis, Garage, Keycloak, FastAPI API + worker, Next.js web, Caddy, Cloudflare Tunnel overlay, observability), with a tested, **multi-tenant** API core (errors, tenancy primitives with row-level-security-scoped sessions, tenant-aware auth and audit log, health, per-tenant app-config and ISP directory, metrics), a committed OpenAPI contract, a generated TypeScript client and CI — so M1 (catalog, customers, hotspot passes) can be built on it.

**Architecture:** A new monorepo `sentech_connect_platform` (sibling of this repo). `apps/api` is a FastAPI modular monolith (one package, modules under `sentech_api/modules/`), `apps/web` is a Next.js 16 app, `packages/api-client` is generated from the API's OpenAPI file. `infra/` holds a base compose file (no host ports), a dev overlay (loopback ports) and a tunnel overlay (Cloudflare Tunnel is the only ingress), modelled on the owner's TTLI_LMS stack.

**Tech Stack:** Python 3.11+, FastAPI, SQLAlchemy 2 (async) + asyncpg, Alembic, PyJWT, arq, prometheus_client, pytest + pytest-asyncio + testcontainers; Next.js 16 / React 19 / TypeScript / vitest; openapi-typescript + openapi-fetch; Docker Compose v2.24+; Caddy; Keycloak 26; Prometheus, Grafana, Loki, Alloy; GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-30-sentech-connect-platform-design.md` (in the `sentech_connect_app` repo). Sections implemented here: §1 (stack), §2 (architecture), §6 (API conventions: `/v1`, RFC 9457, `app-config`), §8 (security/ops baseline), §12 (multi-tenancy foundations: tenants, RLS-scoped sessions, tenant-aware JWT/audit/app-config). Read the spec before starting.

## Global Constraints

Copied from the spec; every task implicitly includes them.

- FastAPI (Python) modular monolith, SQLAlchemy/Alembic, arq workers.
- Next.js 16 web + BFF, TypeScript.
- PostgreSQL with PostGIS and row-level security; Redis; Garage (S3-compatible). *Spec names PostgreSQL 18; this plan pins the PostGIS image `postgis/postgis:17-3.5`, which is known to exist. Task 3 Step 1 checks whether a PostGIS-on-18 image exists and, if so, the image line in `infra/docker-compose.yml` and the `POSTGIS_IMAGE` test default are bumped together. Record the outcome in the README.*
- Keycloak (OIDC); Caddy; Cloudflare Tunnel as the only ingress; Grafana, Loki, Prometheus, Alloy.
- One public API for every client, versioned under `/v1`, OpenAPI generated by FastAPI; errors are RFC 9457 problem details (`application/problem+json`).
- Non-root, read-only, digest-pinned containers with `cap_drop ALL`; private data networks; nothing published on the host in the base/tunnel stack.
- Multi-tenant platform (spec §12): every business table carries `tenant_id` and is protected by PostgreSQL row-level security; the tenant is set per transaction (`SET LOCAL ROLE sentech_app` + `set_config('app.tenant_id', …, true)`) through `tenant_session`; only a `platform_admin` may cross tenants, and every such session is written to the audit log. Sentech is the platform-owner tenant with the fixed id `00000000-0000-0000-0000-000000000001` (slug `sentech`).
- Customers are scoped to one tenant (the same phone number in two tenants is two separate accounts); each tenant will have its own payment account (later milestones).
- Money is integer cents (no money fields in M0, but no float money types may be introduced).
- Secrets come from a gitignored `.env` (generated by `scripts/gen-dev-env.sh`); never commit real secrets.
- Commands are written for Git Bash on Windows (the owner's shell); CI runs the Linux equivalents.

## Review Focus

Failure modes the spec implies but which are easy to miss; each has a test in the task named.

1. **Forged or malformed JWTs** — `alg: none`, HS256 signed with the public key (algorithm confusion), wrong audience, wrong issuer, missing `exp`, token signed by a different key, `Basic` scheme. All must yield 401 `invalid_token`/`missing_token`, never 200 or 500. → Task 6.
2. **`/readyz` with the database down** must return 503 (problem+json), never 200. → Task 3.
3. **Malformed JSON bodies and unhandled exceptions** return problem+json with a stable `code`, do not echo the submitted input, and never leak exception text or stack traces. → Task 2.
4. **Spoofed `CF-Connecting-IP` / `X-Forwarded-For` from a non-tunnel peer** must be ignored by Caddy (only cloudflared's fixed address is trusted). → Task 9.
5. **`audit_log` mutation** — UPDATE, DELETE and TRUNCATE must all be rejected, even for the application's own DB role. → Task 5.
6. **`X-Request-ID` injection** — a client-supplied ID with illegal characters or excessive length is replaced, not reflected. → Task 2.
7. **Cross-tenant reads and writes** — tenant A's session must see zero of tenant B's rows, must not insert rows for tenant B, a session with no tenant set must see nothing (fail closed), and a guard test fails the build if any table with a `tenant_id` column lacks enabled+forced RLS and a policy (so a future migration cannot silently add an unprotected table). → Task 5.
8. **Unaudited platform-admin access** — a `platform_admin` session that crosses tenants must always leave an audit row, and cannot be opened without naming an actor. → Task 5.
9. **Tenant claim abuse** — a customer token with a missing, malformed or non-UUID `tenant_id`, or a forged platform-admin claim without the role, must be rejected (401/403), never silently mapped to another tenant. → Task 6.
10. **Tenant enumeration via the directory** — suspended tenants and tenants with `directory_listed = false` must not appear in `/v1/tenants`; a suspended tenant's `app-config` is 404. → Task 7.

`errors.py`:

```python
import logging
from http import HTTPStatus
from typing import Any

from fastapi import FastAPI, Request
from fastapi.exceptions import RequestValidationError
from fastapi.responses import JSONResponse
from starlette.exceptions import HTTPException as StarletteHTTPException

PROBLEM_JSON = "application/problem+json"
log = logging.getLogger("sentech.api")


class ProblemError(Exception):
    def __init__(
        self,
        status: int,
        title: str,
        code: str,
        detail: str | None = None,
        headers: dict[str, str] | None = None,
    ) -> None:
        super().__init__(f"{status} {code}")
        self.status = status
        self.title = title
        self.code = code
        self.detail = detail
        self.headers = headers


def _problem_response(
    request: Request,
    *,
    status: int,
    title: str,
    code: str,
    detail: str | None = None,
    extra: dict[str, Any] | None = None,
    headers: dict[str, str] | None = None,
) -> JSONResponse:
    body: dict[str, Any] = {
        "type": "about:blank",
        "title": title,
        "status": status,
        "code": code,
        "request_id": getattr(request.state, "request_id", None),
    }
    if detail:
        body["detail"] = detail
    if extra:
        body.update(extra)
    return JSONResponse(body, status_code=status, media_type=PROBLEM_JSON, headers=headers)


def register_error_handlers(app: FastAPI) -> None:
    @app.exception_handler(ProblemError)
    async def _problem(request: Request, exc: ProblemError) -> JSONResponse:
        return _problem_response(
            request,
            status=exc.status,
            title=exc.title,
            code=exc.code,
            detail=exc.detail,
            headers=exc.headers,
        )

    @app.exception_handler(RequestValidationError)
    async def _validation(request: Request, exc: RequestValidationError) -> JSONResponse:
        errors = [
            {"loc": [str(p) for p in e["loc"]], "msg": e["msg"], "type": e["type"]}
            for e in exc.errors()
        ]
        return _problem_response(
            request,
            status=422,
            title="Unprocessable Content",
            code="validation_error",
            extra={"errors": errors},
        )

    @app.exception_handler(StarletteHTTPException)
    async def _http(request: Request, exc: StarletteHTTPException) -> JSONResponse:
        try:
            title = HTTPStatus(exc.status_code).phrase
        except ValueError:
            title = "Error"
        return _problem_response(
            request,
            status=exc.status_code,
            title=title,
            code=f"http_{exc.status_code}",
            headers=dict(exc.headers) if exc.headers else None,
        )

    @app.exception_handler(Exception)
    async def _unhandled(request: Request, exc: Exception) -> JSONResponse:
        log.exception("unhandled error", extra={"request_id": getattr(request.state, "request_id", None)})
        return _problem_response(
            request,
            status=500,
            title="Internal Server Error",
            code="internal_error",
            detail="An unexpected error occurred.",
        )
```

`middleware.py`:

```python
import re
import uuid
from collections.abc import Awaitable, Callable

from fastapi import Request, Response

_REQUEST_ID_RE = re.compile(r"^[A-Za-z0-9._-]{1,64}$")


async def request_id_middleware(
    request: Request, call_next: Callable[[Request], Awaitable[Response]]
) -> Response:
    incoming = request.headers.get("x-request-id", "")
    request_id = incoming if _REQUEST_ID_RE.fullmatch(incoming) else uuid.uuid4().hex
    request.state.request_id = request_id
    response = await call_next(request)
    response.headers["X-Request-ID"] = request_id
    return response
```

```python
from collections.abc import AsyncIterator
from contextlib import asynccontextmanager
from uuid import UUID

from sqlalchemy import text
from sqlalchemy.ext.asyncio import AsyncSession, async_sessionmaker

SENTECH_TENANT_ID = UUID("00000000-0000-0000-0000-000000000001")


@asynccontextmanager
async def tenant_session(
    sessionmaker: async_sessionmaker[AsyncSession],
    *,
    tenant_id: UUID | None,
    platform_admin: bool = False,
    actor: str | None = None,
) -> AsyncIterator[AsyncSession]:
    """A transaction scoped to one tenant (or, for a named platform admin, to all of them).

    Row-level security only applies to non-owner roles, so the transaction runs as
    `sentech_app`. The scope is transaction-local (SET LOCAL semantics) and cannot leak to the
    next user of a pooled connection.
    """
    if platform_admin and not actor:
        raise ValueError("platform_admin sessions must name an actor")
    if tenant_id is None and not platform_admin:
        raise ValueError("tenant_id is required unless platform_admin is set")
    async with sessionmaker() as session:
        async with session.begin():
            await session.execute(text("SET LOCAL ROLE sentech_app"))
            await session.execute(
                text("SELECT set_config('app.tenant_id', :tid, true)"),
                {"tid": str(tenant_id) if tenant_id else ""},
            )
            await session.execute(
                text("SELECT set_config('app.platform_admin', :pa, true)"),
                {"pa": "on" if platform_admin else "off"},
            )
            yield session
```

```python
from collections.abc import Callable
from dataclasses import dataclass
from typing import Any
from uuid import UUID

import jwt
from fastapi import Depends, Request

from sentech_api.errors import ProblemError

_BEARER_CHALLENGE = {"WWW-Authenticate": "Bearer"}
_INVALID_CHALLENGE = {"WWW-Authenticate": 'Bearer error="invalid_token"'}


@dataclass(frozen=True)
class Principal:
    sub: str
    email: str | None
    roles: frozenset[str]
    tenant_id: UUID | None


class JwtVerifier:
    def __init__(
        self, *, issuer: str, audience: str, key_resolver: Callable[[str], Any], leeway: int = 10
    ) -> None:
        self._issuer = issuer
        self._audience = audience
        self._key_resolver = key_resolver
        self._leeway = leeway

    def verify(self, token: str) -> Principal:
        try:
            key = self._key_resolver(token)
            claims = jwt.decode(
                token,
                key,
                algorithms=["RS256"],
                audience=self._audience,
                issuer=self._issuer,
                leeway=self._leeway,
                options={"require": ["exp", "iss", "aud", "sub"]},
            )
        except jwt.PyJWTError as exc:
            raise ProblemError(
                401, "Unauthorized", "invalid_token", headers=_INVALID_CHALLENGE
            ) from exc
        roles = claims.get("realm_access", {}).get("roles", [])
        if not isinstance(roles, list) or not all(isinstance(r, str) for r in roles):
            roles = []
        tenant_id: UUID | None = None
        raw_tenant = claims.get("tenant_id")
        if raw_tenant is not None:
            try:
                tenant_id = UUID(str(raw_tenant))
            except ValueError as exc:
                raise ProblemError(
                    401, "Unauthorized", "invalid_token", headers=_INVALID_CHALLENGE
                ) from exc
        if tenant_id is None and "platform_admin" not in roles:
            # A tenant-scoped token without a tenant is never silently mapped to a default.
            raise ProblemError(401, "Unauthorized", "invalid_token", headers=_INVALID_CHALLENGE)
        return Principal(
            sub=claims["sub"],
            email=claims.get("email"),
            roles=frozenset(roles),
            tenant_id=tenant_id,
        )


def jwks_key_resolver(jwks_url: str) -> Callable[[str], Any]:
    client = jwt.PyJWKClient(jwks_url, cache_keys=True, lifespan=300)

    def resolve(token: str) -> Any:
        return client.get_signing_key_from_jwt(token).key

    return resolve


def get_verifier(request: Request) -> JwtVerifier:
    return request.app.state.verifier  # type: ignore[no-any-return]


def current_principal(request: Request, verifier: JwtVerifier = Depends(get_verifier)) -> Principal:
    scheme, _, token = request.headers.get("authorization", "").partition(" ")
    if scheme.lower() != "bearer" or not token.strip():
        raise ProblemError(401, "Unauthorized", "missing_token", headers=_BEARER_CHALLENGE)
    return verifier.verify(token.strip())


def require_role(role: str) -> Callable[[Principal], Principal]:
    def dependency(principal: Principal = Depends(current_principal)) -> Principal:
        if role not in principal.roles:
            raise ProblemError(403, "Forbidden", "insufficient_role")
        return principal

    return dependency
```

```python
import json
from typing import Any

from sqlalchemy import text
from sqlalchemy.ext.asyncio import AsyncSession, async_sessionmaker

from sentech_api.modules.tenants.schemas import TenantPublic


def _to_public(row: Any) -> TenantPublic:
    branding = row.branding
    if isinstance(branding, str):
        branding = json.loads(branding)
    return TenantPublic(slug=row.slug, name=row.name, type=row.type, branding=branding)


async def find_active_tenant(
    sessionmaker: async_sessionmaker[AsyncSession], slug: str
) -> TenantPublic | None:
    async with sessionmaker() as session:
        row = (
            await session.execute(
                text(
                    "SELECT slug, name, type, branding FROM tenant "
                    "WHERE slug = :slug AND status = 'active'"
                ),
                {"slug": slug},
            )
        ).first()
    return _to_public(row) if row else None


async def list_directory(
    sessionmaker: async_sessionmaker[AsyncSession],
) -> list[TenantPublic]:
    async with sessionmaker() as session:
        rows = await session.execute(
            text(
                "SELECT slug, name, type, branding FROM tenant "
                "WHERE status = 'active' AND directory_listed "
                "ORDER BY is_platform_owner DESC, name"
            )
        )
        return [_to_public(r) for r in rows]
```

```python
from fastapi import APIRouter, Query, Request
from pydantic import BaseModel

from sentech_api.errors import ProblemError
from sentech_api.modules.tenants.schemas import TenantPublic
from sentech_api.modules.tenants.service import find_active_tenant

router = APIRouter(prefix="/v1", tags=["app-config"])


class FeatureFlags(BaseModel):
    hotspot_passes: bool
    rica: bool
    cpe: bool


class LegalVersions(BaseModel):
    terms: str
    privacy: str


class AppConfig(BaseModel):
    tenant: TenantPublic
    min_app_version: str
    feature_flags: FeatureFlags
    legal: LegalVersions


@router.get("/app-config", response_model=AppConfig)
async def app_config(
    request: Request, tenant: str = Query("sentech", pattern=r"^[a-z0-9-]{2,40}$")
) -> AppConfig:
    info = await find_active_tenant(request.app.state.sessionmaker, tenant)
    if info is None:
        raise ProblemError(404, "Not Found", "tenant_not_found", "Unknown tenant.")
    s = request.app.state.settings
    return AppConfig(
        tenant=info,
        min_app_version=s.min_app_version,
        feature_flags=FeatureFlags(
            hotspot_passes=s.flag_hotspot_passes, rica=s.flag_rica, cpe=s.flag_cpe
        ),
        legal=LegalVersions(terms=s.terms_version, privacy=s.privacy_version),
    )
```

```python
import time
from collections.abc import Awaitable, Callable

from fastapi import APIRouter, Request, Response
from prometheus_client import CONTENT_TYPE_LATEST, Counter, Histogram, generate_latest

HTTP_REQUESTS = Counter(
    "sentech_http_requests_total", "HTTP requests", ["method", "route", "status"]
)
HTTP_LATENCY = Histogram("sentech_http_request_seconds", "HTTP request latency", ["method", "route"])

router = APIRouter()


@router.get("/metrics", include_in_schema=False)
async def metrics() -> Response:
    return Response(generate_latest(), media_type=CONTENT_TYPE_LATEST)


async def metrics_middleware(
    request: Request, call_next: Callable[[Request], Awaitable[Response]]
) -> Response:
    start = time.perf_counter()
    response = await call_next(request)
    route = getattr(request.scope.get("route"), "path", "unmatched")
    HTTP_REQUESTS.labels(request.method, route, str(response.status_code)).inc()
    HTTP_LATENCY.labels(request.method, route).observe(time.perf_counter() - start)
    return response
```

- [ ] **Step 2: Digest pinning script**

`scripts/pin-digests.sh`:

```bash
#!/usr/bin/env bash
# Rewrites `image: name:tag` lines in the given compose files to `image: name:tag@sha256:...`.
# Skips images that already have a digest, interpolated images, and locally built ones.
# Usage: scripts/pin-digests.sh infra/docker-compose.yml infra/docker-compose.observability.yml
set -euo pipefail
for file in "$@"; do
  grep -E '^\s+image: ' "$file" | sed -E 's/^\s+image: //' | while read -r image; do
    case "$image" in *@sha256:*|*'$'*|sentech-*) continue ;; esac
    digest=$(docker buildx imagetools inspect "$image" --format '{{.Manifest.Digest}}')
    sed -i "s|image: $image\$|image: $image@$digest|" "$file"
    echo "pinned $image -> $digest"
  done
done
```

